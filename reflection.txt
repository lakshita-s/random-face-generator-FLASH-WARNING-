reflection:

I started this random face generator building off from what we learned in class, trying to make the components my own. I first changed the face to a square and added the second face layer behind it, so it had a border. I wanted to randomize the colors of both the inner and outer layer but still have it match, so I made a second string of colors of the same shades, just different values. I changed some other shapes around- made the outer eyes into squares, the nose into a circle. I learned how to use the quad function to make diamonds for the eyes, because I wanted to give a more regular oval eye shape, but still keep it funky and whimsical. I added another dot to the inner eye as a pupil, and messed around with everything before I settled on changing the face back to a circle for better flow. Then I made the background, using the coding from when we learned about gradients in class, but randomizing the colors instead of using two singular ones. I wanted to do this just as an experiment- I didn't expect this result, but I really liked how it looked- like an old vintage TV malfunctioning screen. I changed the strokes and colors a bit again to match better, and randomized the fill of the outer square eyes too. I then learned how use the mouseX function and a bit of the mapping function, and used it to give my face a changeable smile, as the mouse can drag its small original kind of confused face with the little line into a happier one, making the arc bigger and bigger. I also added the text after this. 

I really liked this project. It made me experiment more and challenge myself, learning new functions and ways to creatively code. I'm happy with my final result, but to improve I would learn how to add a variable to make my constantly randomizing background pausable, and I'd also like to add more features to the face, like eyebrows, teeth, etc. I would also just like to learn more ways to apply the mouseX functions.
